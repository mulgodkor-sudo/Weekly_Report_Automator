[자동 업데이트 - 신규]
 1. 프로그램을 켜면 ECM 배포 폴더(WRA_Patch)에서 새 버전을 확인
 2. 새 버전이 있으면 변경 내용을 보여주고 업데이트 여부 확인 → [예] 선택 시 자동 적용 후 다시 실행
[Plant M/H 입력 확인]
 3. 시차출퇴근 자동 판단: 날짜별 일정으로 출근시각(07:30~09:30) 판단 → ST/OT 계산
 4. 시차출퇴근 직접 선택: 화면 상단 선택 상자(전체 적용) + 날짜 아래 출근시각(▾) 클릭(그날만 변경)
 5. 날짜 머리글에 그날 출근시각 표시, Excel 저장에도 반영
 6. Description(업무명) 빈칸 문제 수정
[Function Code 목록]
 7. 항상 ECM의 FC 엑셀 기준으로 읽음 (모든 시트 검색, CODE 수식 칸도 인식)
 8. ECM 엑셀을 못 읽으면 마지막으로 읽은 사본 사용 + 원인 표시(상태바/사전 검토/M/H 창)
[기타]
 9. 같은 날 같은 제목이라도 Project/Function Code가 다르면 별도 행으로 처리
10. 사전 검토: 시차출퇴근 적용 안내, 화면 오류는 메시지 창으로 표시
